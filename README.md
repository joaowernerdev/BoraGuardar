💰 BoraGuardar

O BoraGuardar é uma aplicação simples de controle financeiro pessoal criada para ajudar o usuário a visualizar e organizar seus gastos de forma prática e intuitiva.

A proposta do projeto é oferecer uma maneira rápida de acompanhar quanto foi gasto e entender melhor como o dinheiro está sendo utilizado no dia a dia.

O BoraGuardar não é uma plataforma de investimentos e não tem como objetivo recomendar aplicações financeiras. Seu foco é exclusivamente o controle e a visualização de gastos pessoais.

🎯 Objetivo

O principal objetivo do BoraGuardar é facilitar o acompanhamento dos gastos do usuário, permitindo visualizar de maneira clara suas despesas e ter uma noção melhor de seus hábitos financeiros.

A aplicação busca ser:

Simples de utilizar;
Fácil de entender;
Visualmente organizada;
Rápida;
Focada no controle de gastos.
✨ Funcionalidades
💸 Controle de gastos

O usuário poderá registrar seus gastos informando dados como:

Valor;
Descrição;
Categoria;
Data.
🏷️ Categorias

Os gastos poderão ser separados por categorias para facilitar a visualização.

Exemplos:

Alimentação 🍔
Transporte 🚗
Lazer 🎮
Moradia 🏠
Compras 🛒
Educação 📚
Saúde 💊
Outros.
📊 Visualização dos gastos

A aplicação apresentará um resumo dos gastos para que o usuário consiga visualizar facilmente quanto está gastando.

Será possível visualizar:

Total de gastos;
Gastos por categoria;
Gastos do período;
Histórico de despesas;
Resumo financeiro.
🧮 Cálculo de gastos

O sistema realizará automaticamente os cálculos necessários para apresentar o total gasto e facilitar o acompanhamento das despesas.

🖥️ Interface

O BoraGuardar terá uma interface simples e intuitiva, desenvolvida para que o usuário consiga registrar e visualizar seus gastos sem complicações.

O foco da interface será:

Organização;
Clareza;
Facilidade de navegação;
Informações objetivas;
Visualização rápida dos gastos.
🛠️ Tecnologias

O projeto será desenvolvido utilizando:

Java — desenvolvimento da aplicação;
C# — desenvolvimento de funcionalidades do projeto;
CSS — estilização e interface visual.
📌 Escopo do projeto

O BoraGuardar foi pensado como um projeto simples para visualização e controle de gastos pessoais.

O projeto não possui:

Sistema de investimentos;
Recomendações financeiras;
Consultoria financeira;
Sistema bancário;
Login de usuários;
Armazenamento de dados em banco de dados;
Integração com bancos ou instituições financeiras.

A proposta é manter a aplicação simples e focada em seu objetivo principal: ajudar o usuário a visualizar seus gastos.

 Resumo mensal;
